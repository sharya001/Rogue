# 2026-10-08

## SVG 图标系统 P0（emoji → 矢量重绘）v3.45.0

**目标**：把游戏里大量 emoji 重绘为 SVG，跨平台一致 + 更立体（Windows 上 emoji 是 Segoe UI Emoji 黑白轮廓，很丑）。

**方案**：`SVG_ICONS` 图标库 + `renderIcon(ch, size)` 渲染辅助，24×24 viewBox、`fill="currentColor"` 继承实体/主题色、单行字符串（map-display 是 `white-space:pre`）、**不用 `<defs>/<id>`**（多实例会撞车）。未命中 emoji 自动 fallback 原字符。

**P0 已画 20 图标**：玩家 4 职业、Boss 龙/精英皇冠/稀有宝石/通用怪、药水/宝箱/钥匙/金币、传送门/锁/城堡、特殊房间 8（祭坛/图书馆/竞技场/赌场/裂痕/训练/许愿井）。均接入 `03-map.js` renderMap 各 text 赋值 + `renderSpecialOverlay`。

**立体感 CSS**（map.css）：`.ic` 加 `filter: drop-shadow(...)` 投影，exit/boss/elite/rare/potion 用 `drop-shadow(0 0 4px currentColor)` 光晕（替代对 SVG 无效的 text-shadow）。

**踩坑（关键）**：
- `const sfx = {...}` 是**跨文件对象**——`01-config.js` 末尾 `const sfx = {` 未闭合，由紧邻的 `02-audio.js`（`play(name){...}` 开头）补全方法并闭合。**新增 JS 模块绝不能在 01-config 和 02-audio 之间插**。图标系统最终并回 01-config.js（gameState 之后、sfx 之前）。
- build.py 的 `JS: SYNTAX ERROR (compile tolerant)` 是 Python `compile()` 编译 JS 的必然误报；`brace imbalance 1 error` 是自定义扫描器对 CSS/既有结构的误报（known cross-file issue）。**权威验证用 node --check 合并脚本**。

**验证**：node --check 合并 JS 通过；运行时 20 图标命中/fallback 正确；CDP 实测浏览器加载 0 error/0 exception；SVG 28px 不溢出 36px 格子；currentColor 正确上色（玩家青/龙红/箱橙/药绿）。截图：`temp/svg-p0-boss-floor.png`、`temp/svg-p0-floor1.png`。
